# 배포 준비 현황

2026-11-05 기준. **스토어 제출 준비 미완료.** 과거 경기 시즌 조회·멘탈지수 API는 Render Free와 Atlas Free에서 실측했고 모바일 앱의 EAS production API 주소도 설정했다. 기존 모바일 빌드와 새 코드는 구분한다.

| 구분 | 상태 | 남은 작업 |
|---|---|---|
| 저장소·CI | 모바일/서버 모노레포, CI 통과, `mobile-release` 환경·토큰 설정, 최종 식별자의 iOS IPA·Android AAB 자동 빌드 성공 | 스토어 업로드·제출 자동화와 운영 모니터링 |
| UI 자동화 | 최신 iOS 시뮬레이터·Android 에뮬레이터 빌드에서 Appium 샘플 흐름과 운영 시즌 집계 조회 통과 | 실기기·원격 푸시·기록 시나리오 및 CI 연결 |
| 모바일 기능 | 샘플 경기·지수·공유·알림 + 2026 시즌 팀별 지수 API 조회, EAS preview/production API 주소 설정, 네이티브 양 플랫폼 운영 API 조회 확인 | 자동 이벤트·개인 기록·통계·사용자 설정 |
| 최신 디자인 | 다크 테마·Bagel·아이보리 CTA 반영 | 구장 시점·팀 색상·hero 및 전체 시안 완성 |
| 서버 기반 | Render Free·Atlas Free 배포, HTTPS readiness 및 시즌·경기 멘탈 조회 확인 | 무료 서비스 지연·백업·접근 정책 검증 |
| 경기 데이터 | 과거 일정·중계 정규화·양 팀 지수 저장, 검증 상태 구분 | 미지원 사건 보완·선수 ID, 실시간 누락·정정·복구 검증, 이용 조건 확인 |
| 기록·통계 | 미완료 | 개인 경기 기록과 시즌·선수 집계 |
| 알림 | 로컬 알림·토큰 검증용 UI | APNs/FCM 설정, 실제 원격 수신, 서버 리마인드·개인화 |
| 배포 자산 | 미완료 | 실제 화면 스크린샷·앱 정보·개인정보 관련 문서 |
| 스토어 | 제출 전. 앱 이름 `왜저럴까`, iOS/Android 식별자 `com.kimbaebae.baseballmental` 확정 | 양 스토어 앱 레코드·계정·테스트 요건 확인, 제출·심사 |

CI 통과는 코드 검사와 번들·컨테이너 생성 성공을 의미한다. 양 플랫폼 스토어용 바이너리 생성은 2026-11-05에 검증했다. 운영 API 조회는 이전 preview 빌드의 두 가상 기기에서 확인했지만, 이번 스토어 바이너리의 실제 iPhone/Galaxy 동작·원격 푸시·개인 기록은 별도 검증이 필요하다.

## CI/CD와 플랫폼별 출시 작업

[CI/CD 점검 및 출시 작업 명세](cicd-release-plan.md)에 현재 설정, iOS·Android별 작업과 완료 기준, 실행 순서를 정리했다. 수동 EAS store 빌드와 GHCR 이미지 publication workflow를 추가했다. 서버는 Render에 수동 배포했고, [최신 모바일 스토어 빌드](release-automation.md)는 성공했다. 스토어 제출은 미완료다. [현재 실행 순서](execution-order.md)를 따른다.

## 데스크톱에서 확인

[시뮬레이터 안내](simulator-testing.md)에 따라 iOS와 Android를 Mac에서 확인한다. 기본 화면·탐색·샘플 지수 변화·레이아웃은 가상 기기로 검증할 수 있다. 원격 푸시, 실제 데이터, 계정·영속 기록은 각각 별도 완료 증거가 필요하다.

과거 경기 기능의 계산 기준·실제 수집 범위는 [2026 시즌 명세](season-mental.md), 파서 증거와 제한은 [정규화 검증](normalization-evidence.md)에 기록한다.
