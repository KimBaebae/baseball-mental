# 배포 준비 현황

2026-11-02 기준. **스토어 제출 준비 미완료.** 현재 빌드는 샘플 데이터 기반 기능 검증용이다.

| 구분 | 상태 | 남은 작업 |
|---|---|---|
| 저장소·CI | 모바일/서버 모노레포, CI 통과 | 지속적인 회귀 검증 |
| UI 자동화 | Appium으로 iOS·Android 샘플 흐름 통과 | 실제 기능 시나리오 확장·CI 연결 |
| 모바일 기능 | 샘플 경기·지수·텍스트 공유·알림 테스트 화면 | 실제 API 연결·기록·통계·사용자 설정 |
| 최신 디자인 | 명세·시안 완료 | 다크 테마·Bagel·구장 시점·팀 색상 앱 적용 |
| 서버 기반 | FastAPI·MongoDB 저장/조회·컨테이너 빌드 | 운영 DB·서버 배포, 인증·접근 정책 |
| 경기 데이터 | 과거 경기 조회·수동 스냅샷 저장 | 선수·아웃·주자 정규화, 실시간 누락·정정·복구 검증, 이용 조건 확인 |
| 기록·통계 | 미완료 | 개인 경기 기록과 시즌·선수 집계 |
| 알림 | 로컬 알림·토큰 검증용 UI | APNs/FCM 설정, 실제 원격 수신, 서버 리마인드·개인화 |
| 배포 자산 | 미완료 | 실제 화면 스크린샷·앱 정보·개인정보 관련 문서 |
| 스토어 | 제출 전 | 최종 식별자·계정·테스트 요건 확인, 제출·심사 |

CI 통과는 코드 검사와 번들·컨테이너 생성 성공을 의미한다. 테스트 APK나 iOS 시뮬레이터 앱을 설치할 수 있다는 사실만으로 운영 서비스 또는 스토어 배포가 준비된 것은 아니다.

## CI/CD와 플랫폼별 출시 작업

[CI/CD 점검 및 출시 작업 명세](cicd-release-plan.md)에 현재 설정, iOS·Android별 작업과 완료 기준, 실행 순서를 정리했다. 검증 CI는 성공했지만 서버·스토어 배포 CD는 아직 없다.

## 데스크톱에서 확인

[시뮬레이터 안내](simulator-testing.md)에 따라 iOS와 Android를 Mac에서 확인한다. 기본 화면·탐색·샘플 지수 변화·레이아웃은 가상 기기로 검증할 수 있다. 원격 푸시, 실제 데이터, 계정·영속 기록은 각각 별도 완료 증거가 필요하다.
