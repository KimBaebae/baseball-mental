# 배포 준비 현황

2026-11-03 기준. **스토어 제출 준비 미완료.** 실제 과거 경기 시즌 조회·멘탈지수 API와 앱 화면을 구현하고 로컬 데이터로 검증 중이다. 기존 배포 빌드와 새 코드는 구분한다.

| 구분 | 상태 | 남은 작업 |
|---|---|---|
| 저장소·CI | 모바일/서버 모노레포, CI 통과 | 수동 배포 후보 workflow 추가, 인증·실행 검증 필요 |
| UI 자동화 | Appium으로 iOS·Android 샘플 흐름 통과 | 실제 기능 시나리오 확장·CI 연결 |
| 모바일 기능 | 샘플 경기·지수·공유·알림 + 2026 시즌 팀별 지수 API 조회 | 운영 API 연결·자동 이벤트·개인 기록·통계·사용자 설정 |
| 최신 디자인 | 다크 테마·Bagel·아이보리 CTA 반영 | 구장 시점·팀 색상·hero 및 전체 시안 완성 |
| 서버 기반 | FastAPI·MongoDB 저장/조회·배포 전 검사·HTTP smoke | 운영 DB·서버 배포, 인증·접근 정책 |
| 경기 데이터 | 과거 일정·중계 정규화·양 팀 지수 저장, 검증 상태 구분 | 미지원 사건 보완·선수 ID, 실시간 누락·정정·복구 검증, 이용 조건 확인 |
| 기록·통계 | 미완료 | 개인 경기 기록과 시즌·선수 집계 |
| 알림 | 로컬 알림·토큰 검증용 UI | APNs/FCM 설정, 실제 원격 수신, 서버 리마인드·개인화 |
| 배포 자산 | 미완료 | 실제 화면 스크린샷·앱 정보·개인정보 관련 문서 |
| 스토어 | 제출 전 | 최종 식별자·계정·테스트 요건 확인, 제출·심사 |

CI 통과는 코드 검사와 번들·컨테이너 생성 성공을 의미한다. 테스트 APK나 iOS 시뮬레이터 앱을 설치할 수 있다는 사실만으로 운영 서비스 또는 스토어 배포가 준비된 것은 아니다.

## CI/CD와 플랫폼별 출시 작업

[CI/CD 점검 및 출시 작업 명세](cicd-release-plan.md)에 현재 설정, iOS·Android별 작업과 완료 기준, 실행 순서를 정리했다. 수동 EAS store 빌드와 GHCR 이미지 publication workflow를 추가했다. 실제 실행·서버 런타임 배포·스토어 제출은 미완료다. [현재 실행 순서](execution-order.md)를 따른다.

## 데스크톱에서 확인

[시뮬레이터 안내](simulator-testing.md)에 따라 iOS와 Android를 Mac에서 확인한다. 기본 화면·탐색·샘플 지수 변화·레이아웃은 가상 기기로 검증할 수 있다. 원격 푸시, 실제 데이터, 계정·영속 기록은 각각 별도 완료 증거가 필요하다.

과거 경기 기능의 계산 기준·실제 수집 범위는 [2026 시즌 명세](season-mental.md), 파서 증거와 제한은 [정규화 검증](normalization-evidence.md)에 기록한다.
